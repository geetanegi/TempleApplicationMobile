# Chat sound effects

To use your own subtle sounds:

1. Add `send.mp3` and `receive.mp3` to this folder.
2. Keep them short (under 2 seconds) and subtle.
3. Update `src/utils/chatSounds.js` to use bundled files instead of URLs (see comments there).

Suggested sources for subtle sounds:
- [Mixkit](https://mixkit.co/free-sound-effects/notification/) – free, no signup
- [Freesound.org](https://freesound.org/search/?q=gentle+notification) – search "gentle notification"
